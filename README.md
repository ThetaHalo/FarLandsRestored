# FarLandsRestored
## About
A plugin to restore the Far Lands on PaperMC servers. The starting coordinates can be configured, including making the entire world Far Lands.

This is a fork of the original plugin, you can find the original [here](https://github.com/OtakuMegane/FarLandsAgain)

## Usage
You can download the latest version [here](https://github.com/ThetaHalo/FarLandsRestored/releases/latest)

### Notice:
Support for this plugin isn't guaranteed, and new features likely won't be added.
